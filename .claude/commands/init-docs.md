# /init-docs - 文档初始化命令

## 功能描述
一键创建完整的项目文档体系。

## 创建文档类型
1. 项目概述文档
2. 架构设计文档
3. 接口文档
4. 数据库设计文档
5. 部署文档
6. 运维文档
7. 用户手册
8. 开发规范文档

## 文档标准
- 遵循RuoYi-Vue-Plus文档规范
- 统一的文档模板
- 标准化的命名规则
- 清晰的版本管理

## 自动化功能
- 根据代码结构生成文档大纲
- 提取代码注释生成API文档
- 数据库表结构自动生成文档
- 配置文件说明自动生成

## 输出位置
- docs/目录下按类别组织
- 使用Markdown格式
- 支持后续编辑和维护
