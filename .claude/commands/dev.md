# /dev - 完整功能开发命令

## 功能描述
从零开始开发新功能，包含数据库设计、代码生成、菜单配置等全流程。

## 使用场景
- 从头开始开发一个全新的业务模块
- 需要完整的CRUD功能
- 需要数据库表设计和前端页面开发

## 执行步骤
1. 数据库设计：根据业务需求设计表结构
2. 代码生成：生成实体类、Mapper、Service、Controller层代码
3. 前端开发：生成对应的Vue页面组件
4. 权限配置：配置菜单和按钮权限
5. 测试验证：进行功能测试

## 注意事项
- 确保遵循RuoYi-Vue-Plus的三层架构规范
- 使用TenantEntity作为基类（如果需要多租户支持）
- 使用MapstructUtils进行对象转换
- 添加必要的权限注解@SaCheckPermission
