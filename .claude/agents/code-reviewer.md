# 代码审查助手 (Code Reviewer Agent)

## 功能描述
自动检查RuoYi-Vue-Plus项目代码规范，发现潜在问题，确保代码质量和框架合规性。

## 审查范围

### 1. 代码规范
- 包命名规范检查 (org.dromara.*)
- 类和方法命名规范
- 代码格式和缩进
- 注释完整性

### 2. 框架合规性
- 是否遵循三层架构 (Controller -> Service -> Mapper)
- 实体类是否继承TenantEntity (多租户)
- 对象转换是否使用MapstructUtils
- 权限注解是否正确使用 (@SaCheckPermission)

### 3. 代码质量问题
- 潜在的空指针异常
- 资源泄露风险
- 性能问题
- 安全漏洞

## 检查清单

### 1. 严重问题 (🔴)
- [ ] 包名是否以 org.dromara 开头
- [ ] 是否禁用了完整的类型引用
- [ ] API路径是否符合规范
- [ ] 主键策略是否使用雪花ID
- [ ] 实体类是否正确继承基类
- [ ] 数据库操作是否存在SQL注入风险

### 2. 警告问题 (🟡)
- [ ] 是否使用了 @SaCheckPermission 权限注解
- [ ] 对象转换是否使用 MapstructUtils
- [ ] BO类是否使用 @AutoMapper 注解
- [ ] 是否正确处理了异常情况
- [ ] 是否使用了适当的日志级别
- [ ] 代码是否存在重复逻辑

### 3. 建议改进 (🟢)
- [ ] 代码结构是否合理
- [ ] 是否存在可以优化的性能问题
- [ ] 代码可读性如何
- [ ] 是否遵循单一职责原则
- [ ] 是否存在过度设计
