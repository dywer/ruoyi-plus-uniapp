# 框架说明

## 项目概述

RuoYi-Vue-Plus 是一个基于 Spring Boot 3.2+ 和 Vue 3 的前后端分离的企业级开发框架。它在原版 RuoYi 的基础上进行了功能增强和优化，提供了更加完善的开发生态。

## 核心特性

### 1. 技术栈先进
- **后端**: Spring Boot 3.2+, MyBatis-Plus 3.5+
- **前端**: Vue 3, Vite, TypeScript, Vben Admin
- **权限认证**: Sa-Token
- **数据库**: MySQL 8.0+, Redis 6.0+

### 2. 架构设计
- **分层架构**: Controller -> Service -> Mapper 三层架构
- **微服务准备**: 良好的扩展性和可拆分性
- **模块化设计**: 功能模块高度内聚，低耦合

### 3. 企业级特性
- **多租户支持**: 完善的租户隔离机制
- **数据权限**: 基于注解的数据权限控制
- **工作流引擎**: 内置流程设计和执行引擎
- **代码生成器**: 快速生成CRUD代码

## 主要模块

### 1. 系统管理 (system)
- 用户管理、部门管理、岗位管理
- 菜单管理、角色管理、字典管理
- 参数配置、通知公告、日志管理

### 3. 监控模块 (monitor)

### 4. 代码生成 (gen)

## 开发规范

### 1. 包名规范
所有包名必须以 `org.dromara` 开头，如：
- `org.dromara.system.controller`
- `org.dromara.common.core`

### 2. 代码规范
- 采用三层架构设计
- 统一使用MapstructUtils进行对象转换
- 使用TenantEntity作为实体基类（支持多租户）
- 权限控制使用@SaCheckPermission注解

### 3. 数据库规范
- 表名使用下划线命名
- 主键统一使用雪花算法
- 必须包含createTime、updateTime字段
- 使用软删除机制
