# 后端开发指南

## 1. 项目结构

RuoYi-Vue-Plus遵循标准的Spring Boot项目结构：

```
src/main/java/
├── org.dromara.system/           # 系统模块
│   ├── controller/              # 控制器层
│   ├── service/                 # 服务层  
│   ├── mapper/                  # 数据访问层
│   ├── domain/                  # 领域模型
│   └── api/                     # API接口
├── org.dromara.common/          # 通用模块
│   ├── core/                    # 核心工具
│   ├── security/                # 安全模块
│   ├── encrypt/                 # 加密模块
│   └── websocket/               # WebSocket模块
└── org.dromara.framework/       # 框架模块
```

## 2. 核心技术栈

- **基础框架**: Spring Boot 3.2+
- **持久层**: MyBatis-Plus 3.5+
- **权限认证**: Sa-Token
- **缓存**: Redis 6.0+
- **数据库**: MySQL 8.0
- **构建工具**: Maven 3.8+

## 3. 代码规范

### 3.1 包命名规范
- 所有包名必须以 `org.dromara` 开头
- 业务模块以 `org.dromara.{business}` 形式组织
- 通用模块以 `org.dromara.common` 开头

### 3.2 实体类规范
- 继承 `TenantEntity` 以支持多租户（如需要）
- 主键使用雪花算法生成（`IdType.ASSIGN_ID`）
- 时间字段使用自动填充

```java
@TableName("sys_user")
@Data
@EqualsAndHashCode(callSuper = true)
public class SysUser extends TenantEntity {
    
    @TableId(value = "user_id", type = IdType.ASSIGN_ID)
    private Long userId;
    
    @TableField(fill = FieldFill.INSERT)
    private Date createTime;
    
    @TableField(fill = FieldFill.INSERT_UPDATE)
    private Date updateTime;
}
```

### 3.3 三层架构规范
- **Controller层**: 处理HTTP请求，调用Service层
- **Service层**: 业务逻辑处理，事务管理
- **Mapper层**: 数据库操作，SQL映射

## 4. 权限控制

### 4.1 认证授权
- 使用Sa-Token进行统一认证
- 通过`@SaCheckPermission`控制接口权限
- 支持多角色、细粒度权限控制

### 4.2 数据权限
- 使用`@DataScope`实现数据权限控制
- 支持部门数据权限、个人数据权限等

## 5. 对象转换

### 5.1 使用MapstructUtils
- 统一使用`MapstructUtils`进行对象转换
- 避免手动逐个赋值
- 支持深度转换和类型映射

```java
// 示例：使用MapstructUtils转换
UserVo userVo = MapstructUtils.convert(user, UserVo.class);
List<UserVo> userVos = MapstructUtils.convert(users, UserVo.class);
```

### 5.2 DTO/VO设计
- DTO用于传输数据，VO用于视图展示
- 合理设计传输对象，避免数据冗余
- 注意敏感信息过滤

## 6. 异常处理

### 6.1 统一异常处理

### 6.2 异常分类
- 业务异常：使用ServiceException
