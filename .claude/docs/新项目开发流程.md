# 新项目开发流程

## 1. 项目初始化

### 1.1 环境准备
- 确认开发环境已安装所需软件
  - JDK 17+
  - Maven 3.8+
  - Node.js 16+
  - MySQL 8.0+
  - Redis 6.0+
  - Git

### 1.2 项目获取
```bash
# 从Gitee获取RuoYi-Vue-Plus项目
git clone https://gitee.com/dromara/RuoYi-Vue-Plus.git
cd RuoYi-Vue-Plus
```

### 1.3 项目配置
- 复制配置文件模板
- 修改数据库连接信息
- 配置Redis连接
- 设置应用基本参数

## 2. 数据库初始化

### 2.1 数据库创建
```sql
-- 创建系统数据库
CREATE DATABASE ruoyi_plus CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2.2 表结构导入
- 执行项目中的SQL初始化脚本
- 导入系统基础数据
- 验证数据库连接

### 2.3 多租户配置
- 如需多租户支持，配置租户相关信息
- 初始化租户管理表结构

## 3. 应用配置

### 3.1 application.yml配置
```yaml
# 数据源配置
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/ruoyi_plus?characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=GMT%2B8
    username: root
    password: password

# Redis配置
  redis:
    host: localhost
    port: 6379
    password: 
    database: 0
    
# 项目基本信息
ruoyi:
  name: RuoYi-Vue-Plus
  version: 5.x
  copyright: RuoYi-Vue-Plus
```

### 3.2 模块启用
- 根据项目需求启用相应模块
- 配置第三方集成（如短信、邮件等）
- 设置文件存储方式

## 4. 项目结构定制

### 4.1 包名定制
- 将所有`org.dromara`包名替换为项目特定包名
- 例如：`org.dromara.company.project`

### 4.2 模块组织
- 按业务领域组织模块
- 保持清晰的包结构层次
- 合理划分通用模块和业务模块

## 5. 安全配置

### 5.1 认证授权配置

### 5.2 安全加固

## 6. 中间件配置

### 6.2 文件存储配置
