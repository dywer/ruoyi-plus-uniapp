# 工具类使用指南

## 1. 概述

本指南介绍RuoYi-Vue-Plus框架中常用的工具类及其使用方法，帮助开发者高效地使用框架提供的各种便捷功能。

## 2. 通用工具类

### 2.1 StringUtils - 字符串工具类

#### 主要方法
- `isEmpty(CharSequence cs)` - 判断字符串是否为空
- `isNotEmpty(CharSequence cs)` - 判断字符串是否不为空
- `hasText(String str)` - 判断字符串是否有内容（去除空白字符后）
- `hasLength(String str)` - 判断字符串是否有长度
- `trim(String str)` - 去除首尾空白字符
- `substringBefore(String str, String separator)` - 截取指定分隔符之前的字符串
- `join(T... elements)` - 拼接数组元素

#### 使用示例
```java
// 判断字符串是否为空
if (StringUtils.isEmpty(username)) {
    throw new ServiceException("用户名不能为空");
}

// 字符串拼接
String[] arr = {"hello", "world"};
String result = StringUtils.join(arr, ",");
// result = "hello,world"
```

### 2.2 ObjectUtils - 对象工具类

#### 主要方法
- `isEmpty(Object[] array)` - 判断数组是否为空
- `containsElement(Object[] array, Object element)` - 判断数组是否包含指定元素
- `isEmpty(Map<?, ?> map)` - 判断Map是否为空

### 2.3 CollectionUtils - 集合工具类

#### 主要方法
- `isEmpty(Collection<?> collection)` - 判断集合是否为空
- `isNotEmpty(Collection<?> collection)` - 判断集合是否不为空
- `union(Collection<T> a, Collection<T> b)` - 集合并集
- `intersection(Collection<T> a, Collection<T> b)` - 集合交集

## 3. 框架专用工具类

### 3.1 MapstructUtils - 对象转换工具类

这是RuoYi-Vue-Plus框架中非常重要的对象转换工具，用于实体类、DTO、VO之间的转换。

#### 使用场景
- Entity与VO之间的转换
- DTO与Entity之间的转换
- 复杂对象的深层拷贝

#### 使用示例
```java
// 单个对象转换
UserVo userVo = MapstructUtils.convert(user, UserVo.class);

// 列表转换
List<UserVo> userVos = MapstructUtils.convert(users, UserVo.class);

// 自定义转换器
UserDto userDto = MapstructUtils.convert(user, UserDto.class, (source, target) -> {
    // 自定义转换逻辑
    target.setCustomField("customValue");
});
```

#### 注意事项
- 严格按照规范使用MapstructUtils进行对象转换
- 避免手动逐个属性赋值
- 使用框架提供的转换器以确保类型安全

### 3.2 ServletUtils - Web工具类

#### 主要方法
- `getRequest()` - 获取HttpServletRequest
- `getResponse()` - 获取HttpServletResponse
- `getBody(HttpServletRequest request)` - 获取请求体内容
- `getClientIpAddress(HttpServletRequest request)` - 获取客户端IP地址

#### 使用示例
```java
// 获取客户端IP
String clientIp = ServletUtils.getClientIpAddress(ServletUtils.getRequest());

// 获取请求体
String requestBody = ServletUtils.getBody(ServletUtils.getRequest());
```

### 3.3 Convert - 类型转换工具类

#### 主要方法
- `toStr(Object value, String defaultValue)` - 转换为字符串
- `toInt(Object value, Integer defaultValue)` - 转换为整数
- `toLong(Object value, Long defaultValue)` - 转换为长整数
- `toDouble(Object value, Double defaultValue)` - 转换为双精度浮点数

## 5. 加密解密工具类

### 5.1 CryptUtils - 加密解密工具类

#### 主要方法
- `aesEncrypt(String data, String key)` - AES加密
- `aesDecrypt(String data, String key)` - AES解密
- `md5(String data)` - MD5哈希
- `sha256(String data)` - SHA-256哈希

#### 使用示例
```java
// 加密
String encrypted = CryptUtils.aesEncrypt("sensitive data", "encryption key");

// 解密
String decrypted = CryptUtils.aesDecrypt(encrypted, "encryption key");
```

## 6. 时间处理工具类

### 6.1 DateUtils - 日期时间工具类

#### 主要方法
- `parseDate(String str)` - 解析日期字符串
- `format(Date date)` - 格式化日期
- `betweenDay(Date before, Date after)` - 计算两个日期相差天数
- `isExpired(Date expireTime)` - 判断时间是否过期

#### 使用示例
```java
// 日期格式化
String formattedDate = DateUtils.format(new Date());

// 计算时间差
long days = DateUtils.betweenDay(startDate, endDate);
```

## 11. 最佳实践

### 11.1 对象转换
- 优先使用`MapstructUtils`进行对象转换
- 避免手动逐个属性赋值
- 确保转换前后字段类型匹配

### 11.2 字符串处理
- 使用`StringUtils`判断字符串空值
- 避免使用`str == null`进行空值判断
- 统一使用框架提供的字符串处理方法

### 11.3 集合操作
- 使用`CollectionUtils`判断集合空值
- 避免直接操作null集合
- 使用工具类提供的安全操作方法

### 11.4 安全处理
- 敏感信息使用`CryptUtils`加密
- 避免明文存储敏感数据
- 遵循最小权限原则

## 12. 注意事项

1. 使用工具类时注意参数校验
2. 对于复杂转换场景，考虑自定义转换器
3. 确保工具类的版本兼容性
4. 在高并发场景下注意工具类的线程安全性
5. 定期检查工具类的性能表现

## 13. 性能优化建议

- 合理使用缓存减少重复计算
- 避免在循环中进行不必要的对象转换
- 使用批处理操作优化大量数据处理
- 注意工具类的内存使用情况

通过遵循此工具类使用指南，可以确保代码的规范性、安全性和可维护性，同时提高开发效率。
