# 工作流开发指南

## 1. 概述

RuoYi-Vue-Plus集成了强大的工作流引擎，使用WarmFlow作为底层工作流引擎，提供可视化流程设计、流程执行、任务办理等完整的工作流功能。

## 2. WarmFlow引擎特性

### 2.1 核心功能
- 可视化流程设计
- 动态流程创建和修改
- 丰富的节点类型支持
- 完整的流程实例管理
- 灵活的任务分配机制

### 2.2 节点类型
- **开始节点**: 流程起始点
- **结束节点**: 流程结束点
- **任务节点**: 用户任务处理节点
- **网关节点**: 分支和聚合节点
- **子流程节点**: 嵌套子流程
- **服务任务节点**: 系统自动处理节点

## 3. 工作流核心概念

### 3.1 流程定义 (FlowDefine)
表示流程的模板定义，包含流程图的XML内容和基本信息。

### 3.2 流程实例 (FlowInstance)
根据流程定义创建的运行时实例，表示一个具体的流程执行过程。

### 3.3 流程任务 (FlowTask)
流程实例执行过程中产生的待办任务，需要用户处理。

### 3.4 流程变量 (FlowVariable)
在流程执行过程中传递的数据变量。

## 4. 工作流集成开发

### 4.1 流程定义创建

```java
// 创建流程定义
FlowDefine flowDefine = new FlowDefine();
flowDefine.setFlowName("请假申请流程");
flowDefine.setFlowCode("leave_apply");
flowDefine.setVersion(1);
flowDefine.setContent(flowXmlContent); // 流程图XML内容
flowDefine.setRemark("员工请假申请审批流程");
flowDefineService.save(flowDefine);
```

### 4.2 流程启动

```java
// 启动流程实例
FlowInstanceRequest startRequest = new FlowInstanceRequest();
startRequest.setFlowCode("leave_apply");
startRequest.setBusinessId(leaveApplyId.toString()); // 关联业务ID
startRequest.setStartUserId(currentUserId);
startRequest.setVariables(getFlowVariables(leaveApply)); // 设置流程变量

FlowInstance instance = flowEngine.startInstance(startRequest);
```

### 4.3 任务办理

```java
// 完成任务
FlowTaskRequest taskRequest = new FlowTaskRequest();
taskRequest.setTaskId(taskId);
taskRequest.setUserId(currentUserId);
taskRequest.setVariables(taskResultVariables); // 任务处理结果变量
taskRequest.setComment(taskComment); // 处理意见

flowEngine.completeTask(taskRequest);
```

### 9.2 事件处理
```java
@Component
public class FlowEventListener implements FlowListener {
    
    @Override
    public void onEvent(FlowEvent event) {
        switch (event.getType()) {
            case TASK_CREATED:
                handleTaskCreated(event);
                break;
            case TASK_COMPLETED:
                handleTaskCompleted(event);
                break;
            case INSTANCE_ENDED:
                handleInstanceEnded(event);
                break;
        }
    }
    
    private void handleTaskCreated(FlowEvent event) {
        // 发送任务待办通知
        notificationService.sendTaskNotification(event.getTaskId());
    }
}
```

## 13. 业务场景示例

### 13.1 请假审批流程
```java
/**
 * 请假申请流程实现示例
 */
@Service
public class LeaveWorkflowService {
    
    @Autowired
    private FlowEngine flowEngine;
    
    /**
     * 提交请假申请
     */
    public void submitLeaveRequest(LeaveApply leaveApply) {
        // 1. 准备流程变量
        Map<String, Object> variables = new HashMap<>();
        variables.put("userId", leaveApply.getUserId());
        variables.put("leaveDays", leaveApply.getLeaveDays());
        variables.put("leaveReason", leaveApply.getLeaveReason());
        
        // 2. 启动流程
        FlowInstanceRequest request = new FlowInstanceRequest();
        request.setFlowCode("leave_apply_process");
        request.setBusinessId(leaveApply.getId().toString());
        request.setVariables(variables);
        
        flowEngine.startInstance(request);
    }
    
    /**
     * 处理审批任务
     */
    public void processApproval(Long taskId, String result, String comment) {
        FlowTaskRequest request = new FlowTaskRequest();
        request.setTaskId(taskId);
        request.setVariables(Map.of("approvalResult", result));
        request.setComment(comment);
        
        flowEngine.completeTask(request);
    }
}
```
