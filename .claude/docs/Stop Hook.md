# Stop Hook - 总结反馈 + 下一步建议

## 功能概述

`stop.js` 钩子在 AI 完成任务后自动触发，提供完成通知、代码变更分析、智能推荐和临时文件清理功能。

## 触发时机

- **当**: AI 完成回答/任务执行完毕时
- **位置**: `.claude/hooks/stop.js`
- **执行**: 自动执行

---

## 核心功能

### 1. 🔔 播放完成音效

**功能**: 播放提示音提醒用户任务已完成

**支持平台**:
| 平台 | 播放方式 |
|------|----------|
| macOS | `afplay` 命令 |
| Windows | PowerShell `SoundPlayer` |
| Linux | `aplay` 命令 |

**音效文件**: `.claude/audio/completed.wav`

**输出示例**:
```
🔔 完成音效已播放
```

**配置方法**:
```bash
# 将音效文件放到指定位置
cp your-sound.wav .claude/audio/completed.wav
```

### 2. 📊 分析代码变更类型

**自动分析内容**:

#### 变更类型识别
| 变更类型 | 触发条件 |
|----------|----------|
| API 接口变更 | 文件包含 `controller` 或 `api` |
| 前端变更 | `.vue`, `.tsx`, `.jsx` 文件 |
| 数据库变更 | `.sql`, `migration` 文件 |
| 测试代码 | 包含 `test` 或 `spec` |
| 配置变更 | `.yml`, `.yaml`, `.properties` |
| 文档更新 | `.md` 文件 |

#### 语言检测
自动识别涉及的开发语言：Java, Vue, JavaScript, TypeScript, SQL, XML, YAML, Markdown

#### 模块检测
自动识别涉及的功能模块：
- Controller / Service / Mapper
- Domain / DTO / VO
- System / Common / Framework

**输出示例**:
```

--------------------------------------------------
  状态：✅ 已完成
  时间：2026-04-06 19:30:00
  变更类型：API 接口变更
```

### 3. 💡 智能推荐下一步操作

**推荐规则引擎**:

基于变更内容和文件类型，智能推荐下一步操作：

| 场景 | 推荐操作 | 建议命令 |
|------|----------|----------|
| 创建 Controller | 编写单元测试 | `mvn test -Dtest=YourControllerTest` |
| 创建 Service | 检查事务注解 | - |
| 创建 Mapper | 验证 SQL 映射 | - |
| 创建实体类 | 检查 TenantEntity 继承 | - |
| 前端组件 | ESLint 检查 | `npm run lint` |
| 测试代码 | 执行测试套件 | `mvn test` |
| 配置文件 | 验证版本控制 | `git status` |
| SQL 脚本 | 执行数据库迁移 | - |

**优先级规则**:
- 🔴 **高优先级**: 安全相关、事务处理、权限检查
- 🟢 **普通优先级**: 代码规范、文档更新

**RuoYi-Vue-Plus 规范检查**:
- 包名必须为 `org.dromara.*`
- 权限注解 `@SaCheckPermission` 检查
- Git 提交建议

**输出示例**:
```
💡 下一步建议
--------------------------------------------------
  🔴 1. 建议：检查是否添加了 @SaCheckPermission 权限注解
  🟢 2. 建议下一步：编写单元测试验证 API 功能
     命令：mvn test -Dtest=YourControllerTest
  🟢 3. 建议：提交代码到 Git
     命令：git add . && git commit -m "feat: 描述本次变更"
```

### 4. 🗑️ 清理临时文件

**清理目标**:

#### Windows 特殊文件
清理 Windows 下误创建的系统保留文件名：
- `nul`, `nul.txt`
- `con`, `con.txt`
- `prn`
- `aux`

#### 临时文件
- `*.tmp` 临时文件（限制清理 10 个）

**输出示例**:
```
🗑️  已清理：/path/to/project/nul
🗑️  已清理：/path/to/project/temp.tmp
```

**安全机制**:
- 仅清理项目根目录下的文件
- 限制清理数量防止误删
- 捕获异常避免中断流程

## 故障排除

### 问题：音效无法播放

**解决**:
1. 检查音效文件是否存在：`ls -la .claude/audio/`
2. 检查文件权限：`chmod 644 .claude/audio/completed.wav`
3. 临时禁用音效：注释掉 `playCompletedSound()` 调用

### 问题：Git 分析失败

**解决**:
- 确认当前目录是 Git 仓库：`git rev-parse --git-dir`
- 非 Git 仓库会跳过分析（预期行为）

### 问题：推荐不准确

**解决**:
- 调整 `NEXT_STEP_RULES` 中的触发关键词
- 添加更具体的文件路径匹配规则

### 问题：临时文件未清理

**解决**:
- 检查文件权限
- 查看错误日志：`console.log` 输出
